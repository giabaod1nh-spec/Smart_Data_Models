## G1 engineering targets

The baseline recorded 4.24 observations/s and the grouped trial recorded 4.45/s. Both used the normal 0.01-second step and both had source pacing below 1×. Use approximately five observations/s at intended pacing as the engineering demand to investigate, with the observed rate and payload bytes as the trial denominator. Verify unchanged captures, then require bounded queues at each durable stage and completion of current work for both window durations. Near five observations/s, valid memberships for two durations can require roughly ten member reads/s before recomputation. Actual completed-work throughput and promotion age must be measured alongside that estimate. Use the current 1 GiB host-memory diagnostic floor and bounded run time. These are provisional engineering criteria. Burst, recovery deadline, latency SLO and deployment resource limits still need evidence and eventual owner approval.

## PERF-04 Silver apply

The normal-step diagnostic identified individual frozen output reconciliation and insert calls as Silver's largest active cost. Group direction obligations within a single event and target table, with a 16-direction cap, verified shared keys, exact per-row comparison and the original single-key proof as fallback. Keep recovery, final Bronze verification, validity and contiguous advancement unchanged. Cross-event grouping poses new ordering and recovery questions and was deferred.

The retained probe cut 110 reads to 32 and measured about a threefold lookup improvement. The full isolated comparison reduced the operation group from about 273 ms to 122 ms per accepted event and raised Silver from 1.64 to 2.09 sequences/s amid different observed source pacing. Gold ACK followed Silver. The bounded oracle still found 194 source observations beyond the Gold prefix and a source-crossed OPEN window. The candidate has a measured local benefit and leaves work to reach the complete-path target.

The next scheduler change removes fixed waits after a full successful pass only when the previously verified prefix still contains entries. It leaves the cap, fault backoff and invalidation-before-change ordering intact. The tests cover verified remainder, exhaustion, contiguous sequences, invalidation precedence and retry behavior. The accompanying diagnostic determines whether reduced poll time raises useful throughput or transfers queuing to Gold.

## PERF-05 Canonical feed and Gold

Actual canonical probes established that archive access and ClickHouse evidence dominate receipt verification time. Reuse the exact direction grouping in the existing public reader, preserving the physical direction inventory and frozen obligation proof. This reduced content queries from 250 to 96 for the same 32 reads and raised retained read rate from 5.49 to 7.41 members/s. The retained result is below the nominal two-window demand, and the paced work path is still unqualified. Next compare actual scheduling, work start and work completion under higher Silver progress. Additional round-trip reductions must retain current validity, complete physical evidence, exact archive revalidation and the existing invalidation fence.

The bound public API, DTOs, SQLite schemas and single-worker ownership support local rollback. Reverting code uses the existing frozen obligations, cursor and membership formats. Persistent caching, cross-event batching and concurrency changes are deferred.

The next read candidate compares full content directly from the bounded physical inventory already read for each fact family. It compares every required field with the matching frozen row, rejects missing keys and conflicting duplicates, and emits the same frozen evidence it verified. The archive context from the entry's initial resolution is reused within that entry. The independent ending archive and source verification still runs. The paired retained probe returned identical full pages and eliminated 96 extra fact queries and 32 redundant archive resolutions per pass. The active direction grouping still applies to Silver writes and recovery.

The Bronze point-read candidate verifies a frozen observation obligation directly from its first query when the namespace, event and revision keys match. Other obligations, including delivery lineage, still use the original reconciliation. It verifies all returned physical mirrors and retains the final SQLite identity check. On retained authority the point-read cost dropped from 1.657 to 1.125 seconds across 64 reads, and full canonical read rate rose from 9.84 to 11.08 members/s. The test covers missing lineage, a divergent physical duplicate and a source transition during the read. This result is a read-side capacity measurement under retained load. The updated live Silver and Gold rates are still unmeasured.
