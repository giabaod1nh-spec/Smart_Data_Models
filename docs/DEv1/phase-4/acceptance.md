Retain one evidence directory per run with assertion-level outcomes, revision/diff inventory, source binding and receipt, page/bundle counts, stage metrics, schema/migration report, V2 sentinels, crash/race snapshots, replay isolation, service inventory and readiness timeline. Mark mocks and actual Silver integration separately; retain failures with resolution notes. Do not use aggregate test counts to waive any row.
