---

## 1. Single Source of Truth

```
Every field consumed by Silver MUST originate from this contract.
Silver MUST NOT infer new business fields.
Silver MUST NOT inspect Kafka events directly.
Silver MUST NOT derive fields that Bronze does not provide.
If a field is not in this contract, Silver does not use it.
```

**Plan 1 locks:**
- Camera → `silver_fact_camera_observation` (`PROCESSED`).
- Store `scenario_id` only — **no** `scenario_type` / `weather` derivation in Silver.
- Normative DDL = `004_create_silver.sql` only.

---

## 2. `cycle_sequence` Definition (Locked)

```
cycle_sequence = monotonically increasing publish sequence
                 generated by Snapshot Provider.

NOT traffic light cycle.
NOT signal phase.
NOT simulation second.
NOT TraCI step.
```

## 7. Enums & Units

**Direction:** `NORTHBOUND`/`NORTH`/`N` → `N` (same for S/E/W).  
**SignalStatus:** `GREEN`/`RED`/`YELLOW`.  
**TrafficStatus:** `LIGHT`/`MODERATE`/`HEAVY`/`CONGESTED`/`UNKNOWN`.  
**TimingMode:** `FIXED_TIME`/`ACTUATED`/`ADAPTIVE`/`MANUAL`.

**Units:** speed km/h; queue meters; occupancy percent 0–100; arrival rate PCU/s; time seconds; coords WGS84 lon/lat.

---

## 8. Null / Quarantine Policy

1. Required missing → `QUARANTINED` (never force `0` for required metrics).  
2. Optional with business default → explicit default.  
3. Optional without default → `Nullable` / `NULL`.  
4. Range violations → quarantine (`INVALID_RANGE_*`).

`quality_status`: `VALID` | `VALID_WITH_DEFAULT` | `QUARANTINED` | `DOCUMENTED_SKIP` | `IDEMPOTENT_SKIP`.  
`quality_flags`: pipe-separated string; empty if none.

## 10. Dimension Lifecycle (SCD Type 1)

- Engine: `ReplacingMergeTree(updated_at)` (dims).  
- Emit dimension row only when `source_hash` changes or first seen.  
- Facts still emit every valid event.  
- Queries: `FINAL` or `argMax(..., updated_at)`.

---

## 11. Lineage

Every fact row MUST carry:  
`source_bronze_event_id`, `source_raw_ingestion_id`, `source_topic`, `source_partition`, `source_offset`, `source_payload_hash`.
